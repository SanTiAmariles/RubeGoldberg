# Máquina de Rube Goldberg — Unity

## Descripción
Proyecto desarrollado en Unity que representa una máquina de Rube Goldberg con rampas, dominós, cubos, físicas y materiales con texturas personalizadas.

## Requisitos
- Unity 6.
- Unity Hub.

## Cómo descargar el proyecto
1. Entrar al repositorio: https://github.com/SanTiAmariles/RubeGoldberg
2. Pulsar **Code → Download ZIP**.
3. Descomprimir el archivo descargado.

## Cómo abrir el proyecto
1. Abrir Unity Hub.
2. Seleccionar **Añadir proyecto desde el disco**.
3. Seleccionar la carpeta descomprimida que contiene `Assets`, `Packages` y `ProjectSettings`.
4. Abrir el proyecto y esperar a que Unity importe los recursos.

## Cómo ejecutar la máquina
1. En el panel Project, entrar a `Assets/Scenes/`.
2. Abrir `RubeGoldberg.unity`.
3. Pulsar **Play** para ejecutar la simulación.

## Estructura del proyecto
- `Assets/`: escenas, materiales, texturas y recursos.
- `Packages/`: paquetes y dependencias.
- `ProjectSettings/`: configuración del proyecto.
- `.gitignore`: archivos excluidos del control de versiones.

La carpeta `Library` no se incluye porque Unity la genera automáticamente.
